我来自湖北鄂州——就是那个面积在湖北 17 个市州里最小、 却装着 1800 多年吴都历史和一座亚洲首个专业货运枢纽机场的地方。

选这个主题，是因为上大学离开家乡之后，我才发现自己其实不太会介绍它。 别人问"鄂州在哪"，我总要说"武汉旁边"； 别人问"武昌鱼是武汉的吗"，我得解释半天三国时的武昌其实是鄂州。 所以这次作业，我想认真地把家乡讲清楚一遍。

做这个网页的过程也像是重新认识家乡：查资料时才发现， 原来凌晨三点我家旁边的机场正忙着分拣来自挪威的三文鱼， 原来梁子湖的螃蟹 24 小时就能到曼谷， 原来湖北简称"鄂"的源头就在我从小走过的路上。

STRUCTURE

这个网站是怎么搭起来的

全站共 7 个 HTML 页面（作业要求不少于 5 个），采用"主页 + 分页面"结构，页面之间全部使用相对路径链接。

目录结构
路径说明

├ index.html主页，含通向所有分页面的链接

相对路径怎么用的

这是作业明确要求的，也是上传 GitHub Pages 后图片不裂的关键：

  • 主页在根目录，引用分页面写 web/overview.html，引用图片写 image/hero.svg，引用样式写 web/css/style.css
  • 分页面在 web/ 下，返回主页写 ../index.html，引用图片写 ../image/xxx.svg，同级引用样式写 css/style.css
  • 分页面之间互跳直接写文件名，如 food.html
  • 全站没有任何绝对路径或本地盘符路径，整个文件夹拷到任何地方、任何服务器都能正常运行

导航与返回

每个页面顶部都有固定导航栏，当前所在页面用彩色高亮标记； 每个分页面底部都有"返回主页"链接，正文末尾还有"上一页 / 下一页"翻页导航； 面包屑（首页 / 当前页）也提供了一条返回路径。

TECH

用到的技术

全部为原生前端技术，不依赖任何第三方库、CDN 或外部字体，双击 index.html 即可离线打开。

H5

HTML5 语义化

使用 header、nav、main、section、footer 等语义标签组织结构； 表格用 caption、thead、tbody 和 scope 属性标注表头关系； 每张配图都写了 alt 描述文本，图片加载失败或读屏时仍能理解内容。

C3

CSS3 样式与动画

用 CSS 变量（自定义属性）统一管理配色与圆角，一处修改全站生效； Flexbox 与 Grid 负责布局；渐变（linear-gradient）、 阴影、圆角、backdrop-filter 毛玻璃效果塑造视觉； @keyframes 实现首页卡片的漂浮与徽章呼吸动画。

RWD

响应式设计

含 viewport meta 标签，采用流式布局； 通过 @media 查询在 960px 和 680px 两个断点重排： 宽屏四列 → 平板两列 → 手机单列，导航自动换行； 字号用 clamp() 平滑缩放，容器用 max-width 约束， 全局 box-sizing: border-box 避免溢出。

SVG

原创矢量插画

站内 12 张原创插图为手写 SVG 代码绘制，包括长江观音阁、西山吴王城、 孙权称帝、梁子湖、武昌鱼、大闸蟹与豆丝、花湖机场、城市天际线、区位示意图、 野生动物王国、书桌场景与首页主视觉等。 矢量格式缩放到任何尺寸都不失真，文件体积极小（全站总计远小于 100 MB 的作业上限）。

JPG

实景照片与来源标注

各页面配图另选用 10 张鄂州实景照片（长江大桥、观音阁、西山、梁子湖、 野生动物王国、花湖机场、武昌鱼、梁子湖大闸蟹等），均通过公开图片检索获取， 并在每张图下方以图注标明来源；部分照片带有原媒体水印（如湖北日报、极目新闻）。 照片仅用于课程作业展示，版权归原拍摄者与媒体所有。

JS

少量原生 JavaScript

仅在页脚用几行原生 JS 自动更新版权年份，无任何外部依赖。 图表（GDP 产业结构条形图、机场货量增长柱状图）用纯 CSS 宽度百分比绘制， 不依赖图表库，保证离线可用。

A11y

可访问性与细节

按钮与链接触控目标不小于 44×44px，移动端表单字号不小于 16px； 支持 prefers-reduced-motion，用户系统开启"减弱动态效果"时自动关闭动画； 颜色对比度按可读性调配；表格容器支持局部横向滚动，不撑破页面。
